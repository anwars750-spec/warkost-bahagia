# V1.3 — Admin Menu & Stock

## Scope
Operational Control Center untuk Admin:
- kategori menu dengan station Kitchen/Bar
- produk: nama, kategori, harga normal, harga jual, stock, image URL, deskripsi, aktif/nonaktif
- audit read-only untuk perubahan kategori dan produk
- role gate Admin melalui Supabase Auth + RLS

## Data flow
Admin UI → Supabase authenticated client → RLS → categories/products

Audit:
categories/products change → database trigger → private audit writer → audit_logs

## Security
- Hanya role `admin` yang dapat insert/update/delete categories dan products.
- Customer/staff hanya membaca sesuai RLS.
- audit_logs tidak dapat ditulis langsung oleh authenticated client.
- Audit trigger menyimpan perubahan produk/kategori.
- Payment status tetap tidak disentuh oleh Admin UI.
